# GIST Frontend Demo

## চালানোর নিয়ম
1. ZIP ফাইলটি Extract করুন।
2. `index.html` ফাইলটি Chrome/Edge-এ খুলুন।
3. সব ফাইল একই ফোল্ডার কাঠামোতে রাখুন; `assets` ফোল্ডারটি সরাবেন না।

## ফাইল
- `index.html` — পেজের কাঠামো
- `style.css` — ডিজাইন ও responsive layout
- `script.js` — mobile menu, semester selector ও demo interactions
- `assets/` — কলেজ ভবন ও GIST লোগো

## গুরুত্বপূর্ণ
এটি Frontend-only demo। Login, database, notice publishing, real course/video/PDF upload এবং student progress এখনো backend-এর সঙ্গে যুক্ত নয়। Footer-এর ইমেইল/ঠিকানা placeholder; প্রকাশের আগে কলেজের সঠিক তথ্য বসাতে হবে।
